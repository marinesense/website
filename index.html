How it works

Data flows one way. Answers stay onboard.

MarineSense sits beside your existing systems, including platforms such as SMARTShip or Vessel Insight. It reads, it never writes, and it keeps working when the satellite link drops.

Offline first

Core assistance needs no internet. Updates are small packages queued for port Wi-Fi or a good satellite window.

Read-only, always

Any write or control path is a hard stop in testing. That keeps the cyber and class approval burden low.

Gaps shown as gaps

Missing data is shown as missing. Values are never repeated or invented to fill a gap.

FAQ

Questions superintendents ask first

Can MarineSense change anything on the ship?

No. It reads through a one-way gateway, and any write or control path is treated as a hard stop in testing. It advises; the Chief Engineer decides.

What happens when the satellite link is down?

Nothing changes for the crew. The model, the manual index and the vessel's history all run on the onboard server. The shore server only syncs and gives a second opinion when the link allows.

Do we need to replace our monitoring platform?

No. MarineSense reads from the systems you already have, whether that is the alarm and monitoring system directly or a platform such as SMARTShip or Vessel Insight.

Whose manuals does it use?

The vessel's own. Manuals stay in the ship's library and are indexed in place, with Chief Engineer approval. They are not copied to other vessels.

How do we know it works before it goes aboard?

We run it on ShipSim first. An instructor injects hidden faults, and your engineers can watch MarineSense find and explain them before you approve any installation.
